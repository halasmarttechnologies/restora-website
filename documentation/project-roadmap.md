# Project Roadmap

## Phase 01: Foundation, navbar, hero (complete, awaiting approval)

- Monorepo with `frontend/`, `backend/` and `documentation/`.
- Next.js, TypeScript (strict), Tailwind CSS, ESLint, Prettier, Vitest.
- Announcement bar, overlay navbar (with mobile menu) and full-height media hero with a
  video-ready placeholder.
- Backend foundation: typed config validation, error base class, composition root.

### Outstanding items

- Brand logo asset (the navbar currently uses a text wordmark).
- Hero background video and poster frame.
- Approved copy for the announcement bar, hero and navigation labels.
- Hosting target and production `NEXT_PUBLIC_SITE_URL`.

## Future phases (each scoped and approved separately)

- Site content and marketing pages.
- Services catalogue.
- Backend framework and database selection.
- Booking and scheduling, therapist management.
- Authentication and customer accounts.
- Payments, notifications, administration.
